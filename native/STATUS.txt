IMPORTANT REPAIRS
Generic values retain native addresses and actual memory widths through calls,
allocation, references, arrays, callbacks and existential packages. Aggregate
lowering preserves original storage. Erased pointer fields and datatype/pattern
projections have explicit concrete views; static generic arrays pack constants
into their logical prefix. The native C ABI is tested with mixed and small
structures and bound callbacks invoked by C.

Wide arithmetic is opaque to the 32-bit proof engine; fat-pointer and wide-index
bounds checks remain at runtime. Undefined Pratt arithmetic remains symbolic.
Pointer identity/order uses full-width bits. Fat indexing checks the final
selected address; extents and shrink products are checked before narrowing or
overflow. Const zero-terminated input is accepted by read-only scan helpers.
Native generator dependency files now rebuild tools after runtime-header edits.

SCOPE / LIMITS
Banshee persistence is same-build, same-ABI, trusted-input checkpointing. Custom
and flowrow expressions require their own codecs. The old serialize_cs helper
remains a stub; use the tested module/object API. Cross-build/cross-ABI snapshots
and hostile-data decoding are not established. Region allocation is pointer-word
aligned, not over-aligned; individual allocations remain capped near 2 GiB.

Production uses BDW-GC 8.2.12, which does not provide malloc-ASan payload redzones.
Its bridge defaults detect_stack_use_after_return=0 because it cannot scan ASan
fake stacks. Separate malloc-backed probes retain those checks. No leak-ignore
list or detect_leaks=0 is used. Libffi 3.5.2 is a runtime dependency; libcrypto is
used for compiler type digests. Generated C uses -fno-strict-aliasing.
Callback caches live for process lifetime; shutdown requires quiescent callers.
The 2,048-closure stress test, live-cache roots and deliberate 73-byte leak control
remain validated. Unsupported adapted variadic/union/bitfield/int128 callback
signatures are rejected. Long/long-long constant patterns and untagged-union
unpacking patterns remain historical language restrictions. Conservative runtime
checks have a performance cost that has not been benchmarked.
